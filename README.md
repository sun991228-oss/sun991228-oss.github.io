# 📋 근무성적 평정 시스템 v2

## 🚀 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```
→ `http://localhost:8501` 접속

## 👥 계정 구조

| 역할 | 설명 | 기본 계정 |
|------|------|-----------|

## 📊 배점 구조

| 항목 | 배점 | 방식 |
|------|------|------|
| 근무실적 평정 (A) | 60점 | 과제별 10점 × 업무비중 × 6 환산 |
| 직무수행능력 (B) | 35점 | 5개 항목 각 7점 |
| 직무수행태도 (C) | 5점  | 5점에서 감점 방식 |
| **합계** | **100점** | |

**평가자 비중:** 1차 30% + 2차 30% + 3차 20% + 4차 20%

## 📁 파일 구성

```
perf_eval_v2/
├── app.py                  # 메인 앱
├── requirements.txt
├── account_template.xlsx   # 계정 생성 템플릿
├── README.md
└── data/                   # 자동 생성
    ├── users.json
    ├── assignments.json    # ee_id → {차수 → [ev_ids]}
    ├── evaluations.json    # ee_id → {차수 → {...}, deductions → {...}}
    ├── tasks.json          # ee_id → {tasks: [...]}
    ├── profiles.json       # ee_id → 인적사항
    └── uploads/            # PDF 파일
```

---

## 🔄 사용 흐름

1. **총괄(admin)** 이 `account_template.xlsx`에 계정·배정 정보 작성 후 업로드
2. **피평가자** 로그인 → 인적사항 입력 → 과제 등록 → PDF 업로드
3. **1차 평가자** 로그인 → 과제 확인 → 근무실적·직무능력·직무태도 평가
4. **2~4차 평가자** 순차적으로 평가 (이전 차수 완료 후 활성화)
5. **총괄** 에서 전체 현황 확인 + 개인별 평정표 엑셀 다운로드
